# My RC Car

I will build my 4-wheel robot car by assembling a simple frame, mounting four DC motors, and connecting an Arduino board in the middle to act as the main brain. I will place an ultrasonic sensor at the front to act as the eyes, an L293D driver chip to control the wheels, a warning buzzer, and a battery pack for power. After wiring all the parts together, I will program the car to drive forward until an obstacle gets closer than 25 centimeters, at which point it will sound the alarm, back up, and turn to find an open path.  How I Will Make It Step-by-StepAssemble the Base: I will mount four DC motors and wheels onto a car frame so it can move using 4-wheel drive.  Mount the Brain: I will place the Arduino board in the center to receive sensor readings and run the movement logic.  Set Up Motor Control: I will wire an L293D motor driver chip between the Arduino and motors to send power to the left and right wheels.  Attach the Eyes: I will place the HC-SR04 ultrasonic sensor on the front bumper to measure distance using sound waves.  Connect the Warning Alarm: I will wire a small piezo buzzer to sound a continuous beep whenever an object gets too close.  Hook Up Power and Code: I will connect a battery pack to run the motors, then upload the program to make the car automatically stop, buzz, and turn away from obstacles.

I learned that the upgraded Adafruit Motor Shield makes running motors much more efficient by using newer TB6612 drivers instead of older L293D chips. This upgrade reduces energy loss so the motors get more power and torque from the batteries, allowing the shield to run up to four DC motors or stepper motors. It lets DC motors spin both forward and backward with super  speed control in  adjustments, making it great for small robotics projects as long as the motors stay under 1.2 amps of continuous power.

I also learned how easily this shield hooks up to both the motors and the Arduino board. For the physical connections, you simply solder two wires to a motor and screw them into terminals M1, M2, M3, or M4. Best of all, because the shield has its own onboard driver chip that handles all the motor speeds through I2C communication, it only uses two Arduino data pins (SDA and SCL). This leaves almost all of the other Arduino pins free for extra sensors and makes the shield compatible with boards like the Uno, Mega, and Leonardo.

```
// Standalone Joystick Reading & Testing Code

const int JOY_X = A3;  // Analog pin connected to VRx
const int JOY_Y = A2;  // Analog pin connected to VRy
const int JOY_SW = 8;  // Digital pin connected to SW (Button)

void setup() {
  Serial.begin(9600);
  
  // Activate internal pull-up resistor for the button
  pinMode(JOY_SW, INPUT_PULLUP);
}

void loop() {
  // Read analog values (Range: 0 to 1023)
  int xValue = analogRead(JOY_X);
  int yValue = analogRead(JOY_Y);
  
  // Read digital button state (LOW = Pressed, HIGH = Released)
  int buttonState = digitalRead(JOY_SW);

  // Output values to the Serial Monitor
  Serial.print("X-Axis: ");
  Serial.print(xValue);
  Serial.print("\t| Y-Axis: ");
  Serial.print(yValue);
  Serial.print("\t| Button: ");
  
  if (buttonState == LOW) {
    Serial.println("PRESSED");
  } else {
    Serial.println("RELEASED");
  }

  delay(150); // Pause briefly to keep the Serial Monitor readable
}
```

## Joystick and Motor Test

I also connected the joystick with the metro board and motor connected and using AI i created a code as show below :

```
#include <Wire.h>
#include <Adafruit_MotorShield.h>

// Motor Shield Instance
Adafruit_MotorShield AFMS = Adafruit_MotorShield();
Adafruit_DCMotor *motorLeft = AFMS.getMotor(1);   // Connected to M1
Adafruit_DCMotor *motorRight = AFMS.getMotor(2);  // Connected to M2

// Joystick Pins
const int JOY_X = A3;  // Controls Speed (0 - 1023)
const int JOY_Y = A2;  // Controls Direction (Forward / Backward)
const int JOY_SW = 8;  // Toggle Button

// System State & Debounce Variables
bool isSystemOn = false;
int lastButtonState = HIGH;
unsigned long lastDebounceTime = 0;
const unsigned long debounceDelay = 50; // 50ms delay to prevent double-triggering

void setup() {
  Serial.begin(9600);
  
  if (!AFMS.begin()) {
    Serial.println("Could not find Adafruit Motor Shield. Check connections!");
    while (1);
  }

  pinMode(JOY_SW, INPUT_PULLUP);

  // Make sure motors start completely stopped
  stopMotors();
}

void stopMotors() {
  motorLeft->run(RELEASE);
  motorRight->run(RELEASE);
}

void loop() {
  int xValue = analogRead(JOY_X);
  int yValue = analogRead(JOY_Y);
  int buttonReading = digitalRead(JOY_SW);

  // --- 1. TOGGLE ON/OFF WITH BUTTON ---
  if (buttonReading != lastButtonState) {
    lastDebounceTime = millis();
  }

  if ((millis() - lastDebounceTime) > debounceDelay) {
    static int currentButtonState = HIGH;
    if (buttonReading != currentButtonState) {
      currentButtonState = buttonReading;
      
      // Trigger state swap when button is physically pressed down
      if (currentButtonState == LOW) {
        isSystemOn = !isSystemOn;
        if (!isSystemOn) {
          stopMotors();
          Serial.println("SYSTEM OFF");
        } else {
          Serial.println("SYSTEM ON");
        }
      }
    }
  }
  lastButtonState = buttonReading;

  // --- 2. MOTOR CONTROL LOGIC ---
  if (isSystemOn) {
    // Map X-axis value (0 to 1023) to PWM speed value (0 to 255)
    int motorSpeed = map(xValue, 0, 1023, 0, 255);
    
    motorLeft->setSpeed(motorSpeed);
    motorRight->setSpeed(motorSpeed);

    // Read Y-axis to determine Direction (Center rests around 500-530)
    if (yValue < 450) {
      // Joystick pushed FORWARD
      motorLeft->run(FORWARD);
      motorRight->run(FORWARD);
      Serial.print("Status: FORWARD | Speed: ");
      Serial.println(motorSpeed);
    } 
    else if (yValue > 570) {
      // Joystick pulled BACKWARD
      motorLeft->run(BACKWARD);
      motorRight->run(BACKWARD);
      Serial.print("Status: BACKWARD | Speed: ");
      Serial.println(motorSpeed);
    } 
    else {
      // Joystick in neutral resting zone
      stopMotors();
      Serial.println("Status: NEUTRAL (Stopped)");
    }
  }

  delay(20);
}
```
